# Flask Web Application 🚀


## 📌 Project Description
This is a Flask-based web application built using Python.  
It demonstrates routing, HTML rendering using templates, and basic web development structure.

---

## ⚙️ Features
* Flask server setup  
* HTML pages using Jinja2 templates  
* Static files support (CSS, JS, images)
  
---

## 🛠️ Technologies Used
* Python  
* Flask  
* HTML  
* CSS  
* JavaScript
